# Data map

Reviewed November 16, 2026.

| Data and source | Purpose | Storage and processors | Retention and deletion path |
| --- | --- | --- | --- |
| PDF selected in the browser | Extract text | The browser reads the file. The app sends text and document names for review. [PDF parser](../../src/features/packet/extract/pdf.ts) | The original file stays on the user's device. The user manages their copy. |
| Extracted text, document names, chosen role, red lines if requested | Produce the review and optionally check preferences | Vercel passes the request to OpenRouter, which routes it to Fireworks AI. [Analysis request](../../src/features/analysis/server/route.ts) · [Model client](../../src/features/analysis/model/openrouter.ts) | App and vendor lifecycles differ. Verify provider retention and deletion before making any guarantee about vendor copies. |
| Guest review input and output | Show the result in the original browser tab | Browser memory. When configured, an encrypted continuation can carry the report through sign-in. [Browser store](../../src/features/review/session/store.ts) · [Continuation](../../src/features/review/session/continuation.ts) | Closing the tab clears its live report state. The continuation option expires after two hours. A guest report reaches the library only after an explicit save. |
| Library review, extracted text, titles, findings, coverage, dates and account ID | Reopen a saved review | Supabase Postgres, with account ownership checks. [Retention migration](../../supabase/migrations/0005_review_retention.sql) | Expires after 30 days or 90 days from the most recent extension. The scheduled purge removes expired live rows. A verified support request can remove a review earlier. |
| First name, email, account ID, password, verification and policy agreement | Authenticate the account and record app signup acceptance | Supabase Auth stores account information and handles passwords. Supabase sends verification email until custom SMTP is activated. Resend is planned. [Signup action](../../src/features/auth/actions.ts) | Account data stays until the account is deleted. Follow the verified support request procedure for earlier action and check vendor copies separately. |
| Essential login, pending confirmation, and optional continuation cookies | Keep the session or return to a review | Browser cookies from the app and Supabase | Session cookies follow auth settings. The pending email cookie can last 24 hours and the review binding up to two hours. Sign-out or browser cookie controls remove applicable local cookies. |
| Personal red lines entered by the user | Review preferences | Supabase Postgres. [Red lines migration](../../supabase/migrations/0003_personal_red_lines.sql) | Keep until the user removes them or the account is deleted. Check the database after a verified account deletion. |
| Contact and feedback form fields or direct support email | Answer messages and process requests | When enabled, Vercel sends form submissions to Formspree. Cloudflare forwards mail to the Google mailbox. [Contact endpoint](../../src/features/site/contact-route.ts) | Keep as needed for response and follow-up. Check both mailbox and Formspree copies, including older entries that are outside the dashboard's free view. |
| IP address, request metadata and email delivery events | Operate, secure and troubleshoot the service | Vercel, Supabase and relevant vendors | Provider-specific. Verify log windows, backup behavior and request handling before promising a deletion deadline for these copies. |

Review documents may contain third-party data. The upload notice asks customers to remove sensitive details before submitting. See [Vendor DPAs](vendor-dpas.md) for the AI contract question and [Retention schedule](retention-schedule.md) for lifecycle details.
