## Limits

The database guard prevents accidental use of the known production hostname outside Vercel Production; it is not an authorization boundary. Hosted staging sign-in recovery with a synthetic account was not exercised for this change. The offline smokes check pipeline behavior using predetermined responses; they do not validate AI accuracy. No migration or model change is part of this release. Vendor questions and future pilot features remain in their tracked states.

## Recovery

Restore the prior working Vercel production deployment if live checks fail. Keep main protection and required checks; reconcile source with a reviewed revert rather than force-pushing main.
