# 0005. Require referenced material before reviewing a lease

If a lease refers to a fee schedule, building rules, addendum, or any other document, Blueline stops the review until every referenced document is provided. It does not issue a partial analysis or a clean conclusion from the uploaded pages alone. A missing referenced document could reverse the apparent meaning of an otherwise ordinary term or contain a cost the main lease never states.

This deliberately gives up immediate partial insight. A signer with an incomplete packet must find the missing material before Blueline can help, and even a routine document reference can block a review close to the signing deadline. The brief must account for reviewing the complete agreement rather than assuming one uploaded file contains every relevant term.
