# 0011. Expire automatic and explicitly saved reviews

Blueline automatically retains a completed lease review in the signer's library for 30 days from the review. If the signer explicitly saves it, the review remains for 90 days from that save, then is deleted. Neither kind of review is permanent.

Automatic retention helps a signer return without remembering to save. The expiry limits how long sensitive lease text remains stored, but it can remove a review the signer expected to revisit. The library must make each expiry clear so “save” is not mistaken for indefinite storage.
