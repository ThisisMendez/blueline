# 0006. Start with pasted text and selectable-text PDFs

The first version accepts pasted lease text and PDFs whose text can be selected. It does not accept DOCX files as uploads. This limits the initial parsing surface while preserving the ability to check that every risk flag cites an exact sentence from the text reviewed.

A lease signer with a Word file must paste its text. Scanned PDFs remain outside the scope already set for the product. The brief should specify the accepted inputs rather than implying that every lease file can be reviewed.
