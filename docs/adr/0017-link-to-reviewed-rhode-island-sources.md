# 0017. Link to reviewed Rhode Island laws from Resources

Blueline’s Rhode Island pilot lists selected official state law links on a Resources page. Keep the lease report and its score based on the documents provided, as specified in [ADR 0014](0014-layer-1-reads-the-lease-not-the-law.md). This pilot gives users a place to read the state’s own text.

Use a small statewide list with a recorded review date and a review deadline. Compare each source with its reviewed fingerprint when the page loads. Withhold a link when its source is unavailable, has changed, or needs review. A problem with the register’s shared scope or annual public-law index withholds all seven links. Use the existing weekly repository check to alert reviewers.

The tradeoff is availability. A state website outage can temporarily remove some or all links. The public Resources page still provides housing help and legal aid links. Publication requires reviewed source baselines and release verification. See the [pilot runbook](../legal/rhode-island-pilot.md).
