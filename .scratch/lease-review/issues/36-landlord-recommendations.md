# 36. Show three to five useful landlord recommendations

Status: implemented for 0.3.0

Show three to five distinct recommendations for a completed landlord review. Start with the strongest cited findings, then use topics absent from the verified six-topic checklist. Where needed, fill the list with clearly marked checks of terms the lease already addresses. Explain whether each item points to existing wording, a topic the report did not find, or a detail for the landlord to confirm. Keep the existing renter shortlist.

For missing topics, provide practical prompts and editable placeholders. For example, ask the landlord to name a repair contact and insert `[repair contact]` where appropriate. Use the existing checklist as the baseline. Leave actual dates, amounts, notice periods, fees, and policy choices to the landlord. A missing topic is a coverage gap and leaves the risk score unchanged.

Check cases with many findings, four missing topics, and no issues with full checklist coverage. Keep the final case useful by suggesting grounded checks without inventing defects. Preserve the existing drafting access and exact quotes. Ship without extra model calls.
