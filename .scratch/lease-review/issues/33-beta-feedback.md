# 33. Ask for feedback during beta

Status: links live in 0.2.0, sending pending ticket 31

Add a small **Give feedback** prompt after the report, where renters and landlords have enough context to say what helped or was missing. Keep a persistent link in the footer for feedback at other points, including when a review fails. Both should open the same form with the topic set to beta feedback.

Start with an optional “Was this useful?” answer and a short comment. Accept feedback from guests and signed-in users. Ask for an email address only if they want a reply. Include coarse context such as the chosen side or source page. Keep lease text, report contents, review IDs, and property addresses out of the submission. Avoid automatic pop-ups and keep marketing opt-in separate.

Reuse the [contact delivery path](31-contact-form-delivery.md) and tag feedback so it can be filtered separately. Verify that the report stays open with the user's selections intact, and that both submission paths reach the inbox.
