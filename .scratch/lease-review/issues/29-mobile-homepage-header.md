# 29. Fit the mobile homepage header in two rows

Status: released in 0.2.0, superseded on mobile by ticket 35

The two-row header shipped in 0.2.0. Follow [ticket 35](35-mobile-menu-and-homepage-cta.md) for the new mobile layout.

Put the Blueline mark and a compact navigation control on the first row. Give **Analyze My Lease** the full second row. Use an accessible menu at widths where the full list of links cannot fit with comfortable tap targets. The menu should still expose How It Works, Features, Pricing, Contact, and My Account.

Verify 320 px and 390 px layouts, zoom, keyboard navigation, and focus. Preserve the desktop navigation and both homepage entry points.
