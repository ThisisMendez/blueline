# Contact delivery options

The [Contact page](../src/app/(marketing)/contact/page.tsx) uses one delivery path for contact messages and beta feedback. The form stays disabled until the server has a Formspree form ID.

| Option | What the free tier covers | What to verify |
| --- | --- | --- |
| **Formspree to Gmail** | 50 submissions per month, email notifications and 30 days of submission history. The configured recipient stays behind a form ID. The submitter’s `email` sets Reply-To, and the `subject` field works on the free plan. [Plan](https://formspree.io/plans/) · [Limits](https://help.formspree.io/articles/account-management/account-limits) · [Reply-To](https://help.formspree.io/articles/building-your-form/email-reply-to-address/) · [Subject](https://help.formspree.io/articles/building-your-form/email-subject-line/) | Verify the destination and test submission, reply, quota and spam handling. Keep the Formspree URL in server configuration so the Blueline route controls which fields are sent. [Spam filtering](https://help.formspree.io/articles/troubleshooting/how-to-prevent-spam/) |
| **Google Apps Script to Gmail** | A web app can receive a POST and run as its owner. MailApp supports a fixed recipient and subject plus the visitor’s Reply-To address. Google currently lists 100 email recipients per day for consumer accounts. [Web apps](https://developers.google.com/apps-script/guides/web) · [MailApp](https://developers.google.com/apps-script/reference/mail/mail-app) · [Quotas](https://developers.google.com/apps-script/guides/services/quotas) | The owner must authorize and deploy the script. Call it from Blueline’s server with an authenticated request and handle quota failures. |
| **Cloudflare Email Routing** | With a domain using Cloudflare DNS, a branded address can forward incoming mail to verified Gmail for free. An app can also send notifications to that verified Gmail address for free via the REST API or a Worker. Cloudflare’s general outbound sending to arbitrary recipients requires Workers Paid. [Domain setup](https://developers.cloudflare.com/email-service/get-started/route-emails/) · [Verified destinations](https://developers.cloudflare.com/email-service/configuration/email-routing-addresses/) · [Pricing](https://developers.cloudflare.com/email-service/platform/pricing/) | Confirm domain ownership and existing MX records before changing DNS. For manual branded replies to arbitrary customers, configure a sender or mailbox separately. |
| **Resend** | Its free tier lists 3,000 emails per month and 100 per day. Production sending uses a verified domain you control. The shared `resend.dev` sender is for tests to the account owner. [Pricing](https://resend.com/pricing) · [Domains](https://resend.com/docs/dashboard/domains/introduction) · [Test sender](https://resend.com/docs/knowledge-base/403-error-resend-dev-domain) | Consider for branded transactional email if a domain is already available. The owner’s mailbox still needs a way to send manual branded replies. |

Start with Formspree for a small beta. Keep the destination private, use the fixed subject `[Blue Line] Website Contact`, put the selected topic in the body, and use the submitter’s address as Reply-To. Validate lengths and allowed topics on the server and handle send errors without clearing the user’s text. Keep lease files and report contents out of the form. Confirm the subject and delivery in Gmail before enabling the production button. [Gmail filters](https://support.google.com/mail/answer/6579)

Contact delivery is separate from account confirmation and password reset. Before prompting more visitors to sign up, verify public signup and email delivery in the existing Supabase project. Supabase’s built-in sender only sends to project organization team addresses. Custom SMTP supports public email delivery. [Supabase Auth email](https://supabase.com/docs/guides/auth/auth-smtp)

If a Blue Line domain is already on Cloudflare DNS, Vercel can call Cloudflare directly with a server-side token. Use the REST API’s `reply_to` field to direct replies to the visitor. [Cloudflare REST API](https://developers.cloudflare.com/email-service/api/send-emails/rest-api/) · [Reply-To field](https://developers.cloudflare.com/email-service/reference/headers/)

## Formspree setup

1. In a Formspree Free project, link and verify the approved support inbox. Create one form with an email notification action that points there. Use Formspree's built-in spam filtering. [Link an inbox](https://help.formspree.io/articles/form-and-project-settings/changing-a-form-email-address/) · [Spam filtering](https://help.formspree.io/articles/troubleshooting/how-to-prevent-spam/)
2. Set `FORMSPREE_FORM_ID` in local server configuration and submit synthetic contact and feedback messages through the app. Verify that they arrive with subject `[Blue Line] Website Contact`, that a supplied visitor email is the Reply-To address, and that feedback contains the `beta-feedback` category. If feedback omits email, check that the notification contains no visitor address.
3. Set the same server-only value for the Vercel Production environment once inbox verification passes. After the production deployment, open Contact and check that sending is available. The inbox address stays in Formspree settings.
