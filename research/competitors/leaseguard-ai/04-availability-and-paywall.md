Sources: the pricing page, the `/analyze` header, the pricing FAQ (from the server-rendered HTML), the terms (section 5) and the sample report.

| | Free | Pro $7.99/mo | Premium $12.99/mo | One-time $19.99 |
|---|---|---|---|---|

| Plain-English explanations | "Basic" | Full | Full | Full |
| Severity level | ✓ | + "severity scoring per clause" | ✓ | ✓ |
| State selection, key state rights box | ✓ | ✓ | ✓ | ✓ |
| Statute reference links | ✗ | ✓ | ✓ | ✓ |
| Negotiation templates | ✗ | every flag | ✓ | ✓ |
| PDF report and email delivery | ✗ | ✓ | ✓ | ✓ |

| Multi-property dashboard | ✗ | ✗ | ✓ | ✗ |
| Co-tenant access | ✗ | ✗ | ✓ | ✗ |
| Deposit Shield | ✗ | ✗ | "coming soon" | ✗ |

**Other policy facts:**
- **Retention:** the document is "never stored" and results are kept 7 days. Pro reports saved to an account are kept until the user deletes them.
- **Refund:** within 48 hours.
- **Payment:** cards, Apple Pay and Google Pay through Stripe.
- **Account:** optional.

**Inconsistencies on the site:**
- Pricing calls $19.99 "Pro-level", but the `/analyze` header labels it "PRO REPORT $19.99 one-time".
- The how-it-works and terms pages say the statute database is updated quarterly, while the FAQ says it "includes … relevant case law for every state".

**What this means for Blue Line:** Blue Line has no payment flow and none is ticketed. The blueprint treats every feature as available to signed-in signers and makes no tiering choice. Pricing is a separate decision for you.
